# Project 01 – Miniature Car Chassis

## Overview

An introductory Siemens NX project completed as part of the *Engineering Design and Material Selection* course at ETH Zurich.

This was my **first project using Siemens NX** and my second CAD project overall, following an introductory water bottle model in Autodesk Fusion 360.

The objective was to construct a simplified miniature car chassis using basic parametric modeling techniques.

## Software
- Siemens NX

## Modeling Process

The chassis was modeled using simplified geometry provided as part of the course exercise.

The modeling process included:

- Creating and dimensioning a 2D sketch
- Applying geometric constraints to define the sketch
- Extruding the profile into a 3D solid
- Using symmetry and mirrored geometry to construct the chassis efficiently
- Combining geometry into the final simplified model

## Key Takeaways

This project introduced me to the Siemens NX modeling workflow and the importance of fully defining sketch geometry before creating 3D features.

Using symmetry also demonstrated how geometric relationships can simplify a model and reduce repetitive construction steps.

The result is a simplified educational chassis model, not a structurally analyzed or optimized vehicle component.
