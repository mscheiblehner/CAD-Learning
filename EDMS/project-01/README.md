# Project 01 – Miniature Car Chassis

## Overview
A basic 3D model of a miniature car chassis, created as part of the *Engineering Design and Material Selection* course at ETH Zurich.

This was my **first project using Siemens NX** and only my **second CAD project overall**, following an introductory water bottle model in Autodesk Fusion 360.

The exercise focused on becoming familiar with a new CAD environment while creating the basic geometry of a miniature car chassis.

## Software
- Siemens NX

## Model
The model consists of two polygonal frame sections connected by a central structure with a rectangular opening.

This project represents an introductory geometry exercise rather than a fully developed or structurally optimized chassis.
