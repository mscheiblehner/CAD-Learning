# Project 01 – Miniature Car Chassis

## Overview
An introductory Siemens NX project completed as part of the *Engineering Design and Material Selection* course at ETH Zurich.

This was my **first project using Siemens NX** and my **second CAD project overall**, following an introductory water bottle model in Autodesk Fusion 360.

The objective was to create a simplified miniature car chassis from a 2D sketch while learning the fundamentals of parametric CAD modeling.

## Software
- Siemens NX

## Modeling Process
The chassis was modeled using a simplified geometry provided as part of the course exercise.

The modeling process introduced:
- Creating and dimensioning 2D sketches
- Applying geometric constraints to define sketch geometry
- Converting a 2D profile into a 3D solid using extrusion
- Using symmetry to simplify the modeling process

## Key Takeaways
This project helped me become familiar with the Siemens NX modeling environment and understand how constrained sketches form the foundation of 3D CAD models.

The result is a simplified introductory chassis model, not a structurally analyzed or optimized vehicle component.
