# Project 02 – Connecting Rod

## Overview
A 3D CAD model of a connecting rod, created as part of the *Engineering Design and Material Selection* course at ETH Zurich.

Building on my first Siemens NX project, this exercise introduced more advanced modeling techniques, including parametric design, Boolean operations, feature patterns, and datum geometry.

The model was developed progressively across multiple exercise sessions, starting from a basic 2D sketch and evolving into a more detailed mechanical component.

## Software
- Siemens NX

## Modeling Process
The connecting rod was modeled step by step following the course exercises.

The modeling process included:
- Creating and fully constraining the initial 2D sketch
- Extruding the sketch to create the base solid
- Defining dimensional relationships using the Expression Editor
- Creating additional sketches on existing part faces
- Using Boolean operations (Unite and Subtract) to add and remove material
- Creating raised circular features and a recessed pocket
- Applying circular feature patterns to create regularly spaced holes
- Adding threaded holes using the Thread and Hole features
- Applying edge blends and chamfers to refine the geometry
- Creating a tangential datum plane to position an additional threaded hole
- Working with the feature history to modify existing operations

## Key Takeaways
This project helped me understand how a mechanical component can be built progressively using parametric features rather than a single modeling operation.

I gained experience with dimensional dependencies, feature-based modeling, reference geometry, and the importance of organizing the feature history to make CAD models easier to modify.

The model was created as a guided CAD exercise and was not independently engineered or validated for a specific mechanical application.
