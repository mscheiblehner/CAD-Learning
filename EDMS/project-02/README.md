# Project 02 – Connecting Rod

## Overview

A connecting rod modeled in Siemens NX as part of the *Engineering Design and Material Selection* course at ETH Zurich.

Building on the introductory chassis project, this guided exercise introduced more complex, feature-based modeling techniques.

The model was developed progressively through multiple construction steps, combining parametric geometry, Boolean operations, patterns, and datum features.

## Software
- Siemens NX

## Modeling Process

The connecting rod was constructed following the course exercises. The modeling process included:

- Creating and fully constraining the initial sketch
- Extruding the base geometry and creating additional sketches on existing faces
- Defining dimensional dependencies using the Expression Editor
- Using Boolean operations (*Unite* and *Subtract*) to create raised features and recessed geometry
- Applying circular feature patterns to generate regularly spaced holes
- Creating threaded holes using the Hole and Thread features
- Using edge blends and chamfers to refine the geometry
- Creating a tangential datum plane for an additional threaded hole
- Editing existing features through the model's feature history

## Key Takeaways

This project demonstrated how a mechanical component can be constructed through a sequence of interconnected, parametric features.

Compared with the introductory chassis, the modeling process required greater attention to dimensional relationships, feature dependencies, and the order of operations.

I also gained experience using datum geometry to construct features that could not be positioned conveniently using the existing principal planes.

The connecting rod was modeled as a guided CAD exercise and was not independently engineered or validated for a specific mechanical application.
