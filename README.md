# Water Bottle CAD Project

This project is my first CAD model created in Autodesk Fusion 360.

The model was created by following the YouTube tutorial:
“Fusion 360 Water Bottle Tutorial” by Product Design Online.

The goal of this project was to learn the fundamentals of:

* sketching
* revolves
* fillets
* basic body manipulation
* working with the Fusion 360 workflow

During the process, I gained practical experience with parametric CAD modeling and became more familiar with the Fusion 360 interface and design workflow.

This repository contains:

* the Fusion 360 project file (`.f3d`)
* screenshots of the sketching and modeling process
* the final bottle model
